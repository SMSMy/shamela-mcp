## أمثلة عملية (محدَّثة)

**البحث عن بيت شعر:**

```
shamela_search_phrase(query="وأفجع من فقدنا من وجدنا")   // العبارة الحرفية أولاً
→ shamela_get_page(book_id=754, page_id=198)              // شرح الواحدي
→ shamela_get_citation(book_id=754, page_id=198)          // إحالة جاهزة
```

**مقارنة روايتين لبيت (مثال واقعي):**

```
shamela_search_phrase(query="فليس لأمر حاول الله جمعه")   // ٣ كتب (أمالي القالي، الدر الفريد، تزيين الأسواق)
shamela_search_phrase(query="فليس لأمر قدر الله جمعه")    // صفر — ثم توسيع AND ونصف العبارة للتثبت
```

**البحث عن كتاب:**

```
shamela_resolve(query="الفوائد", type="book")
أو shamela_search_books(query="الفوائد")
→ shamela_get_book(book_id=212)           // التحقق من التنزيل
→ shamela_get_toc(book_id=212, depth=1)   // الفهرس
→ shamela_get_book_section(book_id=212, title_id=7, max_pages=10)  // باب (10 لا 30!)
```

**جلب آية وتفاسيرها:**

```
shamela_get_aya(surah=2, aya=255)                    // آية الكرسي
→ shamela_list_tafsirs_for_aya(surah=2, aya=255)     // التغطية الحقيقية (حالة لكل كتاب)
→ shamela_get_tafseer_texts(surah=2, aya=255, max_sources=5)  // النصوص معزوَّة لكتبها
```

**التحقق من اقتباس قبل اعتماده:**

```
shamela_verify_quote(quote="إنما الأعمال بالنيات", book_id=9942, page_id=17)
// أحكام: verbatim / differs / partial / not_found / unverifiable
// ويكشف الخلط بين page_id والصفحة المطبوعة
```

**قبل دعوى الإجماع أو السكوت:**

```
shamela_scan_consensus(question="المسح على الخفين")        // مواضع الإجماع والخلاف وشواهدها
shamela_research_scope(term="الاستصناع",
                       synonyms=["بيع الاستصناع"])        // صف لكل مذهب: وجد/سكوت/لا يُدرى
```

**كتاب غير موجود في نتائج البحث:**

```
shamela_suggest_download(query="مغني المحتاج")
// منزَّل عندك؟ متاح للتنزيل (برقمه ورابط صفحته)؟ في الفهرس بلا إتاحة؟
```
